# Estrutura do Projeto Expo

* *package.json*: Define as configurações do projeto, dependências e scripts de execução.
* *package-lock.json*: Registra as versões exatas de cada dependência instalada para garantir consistência.
* *app/*: Pasta responsável pelo roteamento e pelas telas principais do aplicativo (localizada dentro de src/).
* *app.json*: Arquivo de configuração global do projeto (nome, ícone, versão, etc.).
* *assets/*: Pasta que armazena arquivos estáticos, como imagens e fontes.
* *node_modules/*: Contém o código-fonte de todas as bibliotecas e pacotes instalados.
* *.gitignore*: Lista de arquivos e pastas que o Git deve ignorar no controle de versão.
* *.expo/*: Pasta gerada automaticamente pelo Expo com arquivos temporários e cache.
